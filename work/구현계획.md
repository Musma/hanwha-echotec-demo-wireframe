## 산출 규칙 (전 배치 공통)

- 작업 중: 화면 ID당 파일 1개 — `HEL02-05 물리지번 등록 (정보 입력).dc.html` 형식
- 배치 완료 시: 모듈별 통합 파일 1개 — `HELxx <모듈명> (통합).dc.html`
  - 좌측 화면 ID + 화면명 목록, 클릭 전환, 현재 화면 ID 상시 표시
  - 문서 ⑤ 이동관계는 통합본 안에서도 실제 클릭 스루로 동작
  - 개별 화면 파일은 삭제하지 않고 유지
- 최종: `물류Twin 화면설계 전체.dc.html` — 모듈 트리(문서 2장 메뉴 경로) + 웹/태블릿/모바일 구분
- 웹 1920 기준 · 좌측 LNB + 상단 헤더 셸 포함 / 태블릿·모바일은 각 디바이스 프레임
- 표 정렬: 헤더 중앙 · 텍스트 좌측 · 수치 우측 + `tabular-nums`
- 더미 데이터는 현장 개연성 있게(지번 `A-12`, 블록 `B-2104-P03`, `TP-02`, `FL-07`), 목록 8~12행
- 문서에 없는 항목은 만들지 않고 "확인 필요 항목"에 기록

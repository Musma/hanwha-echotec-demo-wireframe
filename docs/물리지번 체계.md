# 물리지번 체계

## 1. 정의

물리지번은 야드/부지 위에 일정 크기의 **격자(Grid)** 를 깔고, 각 격자 칸에 **좌표형 번호**를 부여하는 체계다. 기본 격자 단위는 **10m × 10m**이며, **격자 크기는 시스템 설정으로 조정 가능**하다(§4 참조).

## 2. 기준점과 방향

기준점은 격자 영역의 **좌상단 끝**이다.

- 좌상단 끝 = `(000, 000)`
- **오른쪽**으로 갈수록 첫 번째 값(`A`)이 증가
- **아래쪽**으로 갈수록 두 번째 값(`B`)이 증가

즉 물리지번 `(A, B)`의 의미는 다음과 같다.

| 값 | 의미 |
| --- | --- |
| `A` | 좌상단 기준 **오른쪽 방향** 몇 번째 칸인지 |
| `B` | 좌상단 기준 **아래쪽 방향** 몇 번째 칸인지 |

## 3. 표기 규칙

- 각 숫자는 **3자리 zero-padding** (`000` ~ `999`)
- 표기 형식: `(A, B)` — 예 `(012, 007)`
- UI 표시 시 숫자는 `font-variant-numeric: tabular-nums` 적용

### 예시 (기본 10m 격자)

| 위치 | 물리지번 | 좌상단 기준 실거리 |
| --- | --- | --- |
| 좌상단 끝 | `(000, 000)` | 0m, 0m |
| 오른쪽 1칸 | `(001, 000)` | 10m, 0m |
| 아래로 1칸 | `(000, 001)` | 0m, 10m |
| 오른쪽 12칸 · 아래 7칸 | `(012, 007)` | 약 120m, 약 70m |

## 4. 격자 크기 조정

격자 한 칸의 크기는 **고정값이 아니다.** 부지 특성·운영 정밀도에 따라 변경할 수 있으며, 기본값은 10m × 10m다.

- 격자 크기(`cellSize`)는 격자 영역 단위로 설정한다.
- 물리지번 번호 체계(`(A, B)`, 3자리, 좌상단 기준, 우/하 증가)는 격자 크기와 **무관하게 동일**하다.
- 실거리 환산은 항상 `거리 = 칸 번호 × cellSize` 로 계산한다.
  - 예) `cellSize = 5m` 일 때 `(012, 007)` → 오른쪽 60m, 아래쪽 35m
- 격자 크기를 변경하면 기존 칸 번호와 실제 위치의 대응이 달라지므로, **격자 영역 등록 후 크기 변경은 재계산·이력 기록 대상**이다.
